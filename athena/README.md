# 🧠 Athena 2.1 — التواجد والحركة والتنبيه عن السقوط عبر Wi‑Fi CSI

اللوحة بتبعت بيانات Wi‑Fi CSI للكمبيوتر. التطبيق بيعرض التواجد المحتمل والحركة، ويضيف تنبيهًا بحثيًا عند ظهور نمط قد يشبه السقوط، بجانب تصنيف الأنشطة بعد التدريب.

## التشغيل (3 خطوات)

1. **اللوحة:** افتح لوحة التحكم بتاعتها ← تبويب «الشبكة والوضع» ← الدور = **بث CSI للكمبيوتر** ← حفظ ← إعادة تشغيل.
   (اللمبة بتفضل منوّرة طول ما هي بتبث.)
2. **الكمبيوتر** (على نفس الواي فاي):
   ```bash
   cd athena
   pip install -r requirements.txt
   python -m athena
   ```
   الصفحة بتفتح على `http://127.0.0.1:8000`. المفروض يظهر «متصل» ومعاه إطار/ث.
   لو مظهرش: اكتب عنوان الكمبيوتر في خانة «عنوان الكمبيوتر» في اللوحة، وتأكد إن الـ Firewall بيسمح بـ UDP 5005.
3. **سجّل ← درّب ← جرّب** من نفس الصفحة.

بدون لوحة؟ جرّب الشغل كله بلوحة وهمية: `python tools/fake_esp.py`

## المراقبة المتكاملة الجديدة

1. شغّل اللوحة على وضع **CSI stream** زي خطوات التشغيل فوق.
2. افتح التطبيق وسيب الغرفة فاضية، والراوتر واللوحة ثابتين.
3. اضغط **عاير الغرفة وهي فاضية** وانتظر 10 ثوانٍ. خط الأساس بيتحفظ في `athena/models/room_baseline.json`.
4. بعد المعايرة، التطبيق يعرض **التواجد المحتمل** و**الحركة**. لو ظهر نمط تغير مفاجئ ثم سكون مع وجود محتمل، هيعرض **اشتباه سقوط** ويطلب التحقق البشري.
5. لتجربة تصنيف سقوط مخصص، سجّل فئة `fall` بشكل آمن، وسجّل معها فئات مقارنة مثل `lying_down` و`sitting_down` و`walking`، ثم درّب الموديل. لا تعتمد على فئة `fall` وحدها.

### حدود مهمة جدًا

- استشعار CSI هنا مبني على **سعة الإشارة فقط** (64 subcarriers)، لذلك التواجد يتأثر بتغيير مكان الراوتر/اللوحة، الأبواب، الأثاث، الأشخاص الآخرين والتداخل اللاسلكي.
- معايرة الغرفة مطلوبة بعد تغيير مكان الراوتر أو اللوحة أو نقل النظام لغرفة أخرى.
- تنبيه السقوط الحالي **تقديري** وليس كاشفًا طبيًا أو نظام إنقاذ. قد يفوّت سقوطًا أو يعطي إنذارًا كاذبًا. لا تستخدمه لمراقبة شخص معرض للخطر ولا تستبدل به الإشراف البشري.
- لو بتسجل بيانات سقوط، ممنوع تنفيذ سقوط حقيقي أو القفز/الرمي على الأرض. استخدم محاكاة حركة متحكم فيها على سطح لين وتحت إشراف شخص بالغ، وتوقف لو في أي ألم أو خطر.
- الاختبارات المرفقة تستخدم بيانات اصطناعية، ولا تثبت الدقة في بيت حقيقي. لازم اختبار منفصل في غرف وأشخاص مختلفين وتوثيق false positives / false negatives قبل أي استنتاج بحثي.

## إزاي تاخد نتيجة كويسة
- سجّل **10 مرات على الأقل** لكل نشاط (20 ثانية كل مرة)، وغيّر مكانك واتجاهك.
- لازم نشاط **empty** (الأوضة فاضية) و **sitting_still**، وإلا الموديل هيفتكر إن فيه حركة طول الوقت.
- ثبّت اللوحة والراوتر في مكانهم. لو اتحركوا لازم تسجّل تاني.
- الدقة اللي بتظهر بعد التدريب على **نفس المكان والشخص**. جرّبه في أوضة تانية قبل ما تعتمد عليه.
- **ماتستخدمهوش لكشف السقوط أو أي حاجة تخص السلامة.**

## الموديل القديم (`pretrained/`)
ده موديل `athena-cnn-bilstm-0.2` اللي اتدرّب على dataset اسمها esp_fi_har بنتايج 73.5% على نفس الغرف والأشخاص.
مش هيشتغل مباشرة على لوحتك لأن طريقة تجهيز بياناته مجهولة. فيه خيار «ابدأ من الموديل القديم» كنقطة بداية للتدريب (تجريبي وممكن ما يفرقش).

## 🔬 قياس الأداء في أوضة جديدة
بعد ما تسجّل في أكتر من أوضة: `python -m athena.crossval --group room --baseline-only`
(و`--ablate` للمقارنة مع/بدون `normalize_window`). التفاصيل في [`EXPERIMENTS.md`](EXPERIMENTS.md).
